# Crop Recommendation Project 🌱

## Overview

This project uses Machine Learning to recommend the best crop based on soil nutrients and environmental conditions.

## Features

* Crop prediction using ML
* Data preprocessing
* Model training and testing
* Jupyter Notebook implementation
* Python-based project

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## Files Included

* `Crop_recommendation_project.ipynb`
* `app.py`
* `crop_model.pkl`
* `Crop_recommendation.csv`

## How to Run

1. Install Python
2. Install required libraries:

```bash
pip install pandas numpy scikit-learn
```

3. Run the notebook or app:

```bash
python app.py
```
